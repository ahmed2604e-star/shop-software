# AL-NOOR-FRAGRANCES — demo storefront

## Files
- `index.html`: page structure and sample product content
- `style.css`: responsive luxury black, gold and ivory styling
- `script.js`: product search/filter, demo cart, review carousel, newsletter feedback and WhatsApp checkout handoff
- Footer includes visible Instagram, Facebook, and TikTok SVG icons
- Product cards include a premium rounded Add to Cart button with hover animation

## Run locally
Open `index.html` in a browser. Internet is needed for Google Fonts and the hero/promo background photos. Product card images are stored locally in the `images/` folder and will load offline.

## Before using for a real business
1. Replace the demo WhatsApp number `923001234567` in `script.js` and `index.html` with your WhatsApp Business number (digits only in the wa.me URL).
2. Replace demo product names, prices, reviews, and imagery with your actual products and licensed photos.
3. Connect checkout to a backend, order database, inventory management, email/WhatsApp notification service, courier API, and a supported Pakistani payment gateway. This front-end alone does not securely process payments, save orders, or provide admin management.
4. Update contact details, policies, delivery/return terms, and the newsletter form to use real services.
5. Deploy using HTTPS and test mobile, accessibility, order validation, security, and backups.

This is a front-end prototype, not a production-ready ecommerce backend.
